Adafruit GFX Editor is a vector based visual editor for Adafruit GFX compatible displays including a real time preview of the screen.

First Steps

Start by entering your screen Width and Height under "Configure Screen". Now you can create objects in the object editor on the right and change their properties to your desire. When finished hit "Generate Code" to generate the Arduino code for your view. In the Desktop App (in development) you can directly send your current view to the display for a real preview.

Objects can be reordered via Drag and Drop on their name.
Save in Browser

The current view will be saved in your browsers local storage and automatically loaded when you visit the site for the next time. This is only for temporary saves, make sure to not clear your browser data before saving important changes to a proper file.

Generated AdafruitGFX Code

Only the code for drawing the created objects on the screen is generated, you first need to create an Adafruit GFX instance with the correct driver and initialize the display yourself. The name of the Adafruit GFX instance can be changed under "Configure Screen" if desired. If custom fonts were selected make sure to include them at the beginning of the program.
